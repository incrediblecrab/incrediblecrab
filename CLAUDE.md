# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) and GitHub Copilot CLI when working in this repository.

This is the GitHub profile repository: its `README.md` is the page shown at github.com/incrediblecrab. The repository is public. There is no code; the README is the whole product, and GitHub renders only it on the profile.

## Rules

Every factual line (title, employer, apps, sites, counts such as the national parks visited) must agree with the owner's background reference, `~/Documents/resume/resume.md`, whose factual baseline is `resume.tex`; check there rather than inferring. Every app, site and package listed must be live and public: App Store links resolve, and private repositories are never linked or described as open source. Keep the shields.io badges and inline SVG data URIs intact, since GitHub's renderer is unforgiving of broken image markup. Check the result as GitHub renders it (or with `gh api repos/incrediblecrab/incrediblecrab/readme`) after a change, not only as plain Markdown.
